# 🛍️ Group Purchase Platform

Платформа для коллективных закупок, позволяющая пользователям объединяться для покупки товаров по оптовым ценам.

## Особенности

- Аутентификация пользователей (регистрация, вход, JWT токены)
- Каталог товаров с фильтрацией и поиском
- Создание и присоединение к групповым закупкам
- Отслеживание прогресса набора участников
- Адаптивный дизайн для всех устройств
- Row Level Security для защиты данных

## Технологии

### Frontend
- React 18
- React Router 6
- Ant Design 5
- Axios
- Vite

### Backend
- Node.js
- Express
- Supabase
- JWT
- bcrypt

## Установка

### Предварительные требования

- Node.js 18.x или выше
- npm или yarn
- Аккаунт Supabase

### Клонирование репозитория

```bash
git clone https://github.com/yourusername/group-purchase-platform.git
cd group-purchase-platform
```

### Установка зависимостей
```bash
npm install

cd client
npm install
```
